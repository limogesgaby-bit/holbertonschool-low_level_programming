## Description

Ce projet introduit les structures en C (`struct`) et l'utilisation de `typedef` pour simplifier leur écriture. Chaque tâche définit ou manipule une structure dans un header inclus par les fichiers de test.

## Contenu

- `dog.h` : définition de `struct dog` (champs `name`, `age`, `owner`), avec include guard.
- `0-main.c` : fichier de test fourni (non obligatoire à pousser).
