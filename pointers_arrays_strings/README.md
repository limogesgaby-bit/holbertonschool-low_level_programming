# C - More pointers, arrays and strings

Exercices C sur les pointeurs, les tableaux et les chaînes de caractères.

| Fichier | Description |
|---|---|
| 0-strcat.c | Concatène deux chaînes (`_strcat`) |
| 1-strncat.c | Concatène deux chaînes en utilisant au plus n octets de src (`_strncat`) |
| 2-strncpy.c | Copie une chaîne en utilisant au plus n octets (`_strncpy`) |
| 3-strcmp.c | Compare deux chaînes (`_strcmp`) |
