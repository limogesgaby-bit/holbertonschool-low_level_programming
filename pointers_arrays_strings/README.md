# C - Pointers, arrays and strings

This project introduces pointers, arrays and strings in C.

## Learning objectives

- What pointers are and how to use them
- What arrays are and how to use them
- The differences between pointers and arrays
- How to use and manipulate strings
- Scope of variables

## Requirements

- Compiled on Ubuntu 20.04 LTS with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty style (checked with `betty-style.pl` and `betty-doc.pl`)
- No global variables, no standard library functions (only `_putchar`)
- No more than 5 functions per file

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with all function prototypes |
| `0-reset_to_98.c` | Function that updates the value pointed to by an `int *` to 98 |
