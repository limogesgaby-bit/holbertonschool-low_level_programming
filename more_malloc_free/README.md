# More malloc, free

Holberton project: functions using malloc and free.

## Files

- `main.h`: prototypes of all the functions of the project.
- `0-malloc_checked.c`: allocates memory with malloc and exits with status 98 on failure.
- `1-string_nconcat.c`: concatenates s1 with the first n bytes of s2 in newly allocated memory.

## Compilation

gcc -Wall -pedantic -Werror -Wextra -std=gnu89 *.c -o a
